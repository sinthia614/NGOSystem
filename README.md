# NGO Management System

Our NGO Management System designed to help nonprofit organizations manage their daily operations efficiently, securely, and transparently. The system centralizes donor management, beneficiary tracking, project monitoring, volunteer coordination, distribution records, and financial reporting in one platform.

## Features

- User and Admin Authentication
- Member and Committee Management
- Donor and Donation Tracking
- Beneficiary Registration and Monitoring
- Project Planning and Progress Tracking
- Relief Distribution Management
- Volunteer Management
- Financial Reporting Dashboard
- Role-Based Access Control

## Modules

### Authentication
Secure login system for users and administrators.

### Member Management
Manage NGO members, roles, contact details, and joining information.

### Donor Management
Store donor information, donation history, and contribution tracking.

### Beneficiary Management
Maintain beneficiary details, project assignments, and support status.

### Project Management
Create projects, assign budgets, monitor deadlines, and track progress.

### Distribution Management
Track distributed items, beneficiaries, project allocation, and distribution history.

### Volunteer Management
Manage volunteer information, assignments, and project involvement.

### Reports
View total donations, expenses, and financial balance in dashboard reports.
